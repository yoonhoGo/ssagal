# "싸갈!" 플로팅 앱 — 설계 문서

작성일: 2026-06-11

## 개요

Tauri로 만드는 데스크톱 장난감 앱. 화면 위에 항상 떠 있는 작은 말풍선 버튼("싸갈!")을
누르면 "쌰~갈~!" 음성이 재생된다. 연타하면 계속 재생되고, x3/x5/x10 프리셋으로
지정한 횟수만큼 자동 반복할 수 있다.

## 핵심 결정 사항

| 항목 | 결정 |
| --- | --- |
| 앱 형태 | 플로팅 윈도우 (always-on-top, 프레임리스, 투명 배경, 드래그 이동) |
| 음성 소스 | 웹뷰 내장 Web Speech API(`speechSynthesis`), 한국어 음성 |
| 버튼 글자 | `싸갈!` (이미지 키링 디자인 차용) |
| TTS 발화 텍스트 | `쌰~갈~!` |
| 반복 조작 UI | 프리셋 버튼 `x3` / `x5` / `x10` + `중지` |

## 아키텍처

- **Tauri 2.x** 단일 윈도우 앱.
- 프론트엔드는 **순수 HTML/CSS/JS** (프레임워크 없음 — 화면이 단순해 불필요).
- **TTS는 프론트엔드 `speechSynthesis`로 완결.** macOS WKWebView가 시스템 한국어
  음성(예: Yuna)을 사용. Rust 백엔드의 오디오/명령 호출 플러그인이 필요 없어 권한·설정이
  단순하다.
- Rust(`src-tauri`)는 윈도우 생성·설정만 담당하고 비즈니스 로직은 두지 않는다.

### 모듈 경계

| 단위 | 책임 | 의존성 |
| --- | --- | --- |
| `index.html` | 말풍선 버튼 + 프리셋 + 중지 버튼 마크업 | `style.css`, `main.js` |
| `style.css` | 말풍선/입체감/프리셋 pill/누름 애니메이션 스타일, 번들 폰트 | 번들 폰트(Jua) |
| `speak.js` | TTS 발화 + 자동 반복 상태 머신 (순수 로직, DOM 비의존) | Web Speech API |
| `main.js` | DOM 이벤트를 `speak.js`에 연결, 진행 카운트 표시, 윈도우 드래그 | `speak.js` |
| `src-tauri/` | 프레임리스·투명·always-on-top 윈도우 설정 | Tauri |

`speak.js`는 DOM에 의존하지 않게 분리해 단위 테스트 대상으로 삼는다.

## 윈도우 설정 (`tauri.conf.json`)

- `decorations: false` (프레임 없음)
- `transparent: true` (말풍선만 둥실 떠 보이게)
- `alwaysOnTop: true`
- `resizable: false`, 고정 크기 약 **240 × 280**
- `skipTaskbar: true` (작업표시줄/Dock 노출 최소화)
- 드래그 이동: 말풍선 영역에 `data-tauri-drag-region` 적용

## UI 구성 (한 화면)

1. **큰 "싸갈!" 말풍선 버튼** — 누를 때마다 즉시 "쌰~갈~!" 1회 발화.
   연타 시 직전 발화를 끊고 새로 재생(반응성 우선).
2. **프리셋 줄**: `x3` `x5` `x10` 둥근 pill 버튼 — 누르면 해당 횟수만큼 자동 반복.
3. **`■ 중지` 버튼** — 자동 반복 중 즉시 멈춤.
4. **진행 카운트** 표시(예: `3 / 5`). 유휴 시 숨김 또는 비표시.

## 버튼 디자인 (이미지 반영)

- **모양**: 흰색 둥근 말풍선(타원형) + 굵은 검정 외곽선(약 6~8px) + 좌하단 꼬리(tail).
  뒤쪽에 검정 받침을 살짝 오프셋해 키링 같은 입체 그림자.
- **글자**: `싸갈!`을 굵고 둥근 폰트로. 가장 비슷한 무료 폰트는 **Jua**(둥글고 도톰).
  오프라인 동작을 위해 **폰트 파일을 앱에 번들**(웹 폰트 CDN 의존 금지).
  글자에 다중 그림자/스트로크를 주어 키링처럼 **양각 입체감** 연출.
- **누름 피드백**: `:active` 시 살짝 scale down + 그림자 축소로 "꾹" 눌리는 촉감.
- 프리셋·중지 버튼: 말풍선 톤에 맞춘 **검정 테두리 + 흰 배경의 둥근 pill** 스타일로 통일.

## 음성 / 반복 상태 머신 (`speak.js`)

상태:

- `isAutoPlaying: boolean`
- `remaining: number` — 남은 자동 반복 횟수
- `total: number` — 진행 표시용

동작:

- `speakOnce()` — 직전 발화를 `cancel()` 후 `쌰~갈~!` 1회 발화.
- `startRepeat(n)` — `total=n`, `remaining=n`로 세팅하고 자동 반복 시작.
  타이머 race를 피하기 위해 한 발화의 `utterance.onend`가 끝나면 다음 발화를
  트리거하는 **체인 방식**. 발화 간 간격은 짧게(약 300ms).
- `stop()` — `speechSynthesis.cancel()`로 큐를 비우고 카운트 리셋.
- 한국어 음성 선택: `getVoices()`에서 `lang`이 `ko`로 시작하는 음성 우선,
  없으면 기본 음성 fallback. 음성 목록 로딩 지연은 `voiceschanged` 이벤트로 대응.

## 엣지 케이스

- 한국어 음성이 시스템에 없을 때 → 경고 없이 기본 음성으로 발화.
- 자동 반복 중 "싸갈!" 또는 다른 프리셋 클릭 → 기존 반복 취소 후 새 동작 시작.
- `voiceschanged` 이벤트로 음성 목록 비동기 로딩 대응(초기 클릭에서 음성이 비어있는 경우).
- 윈도우 투명/프레임리스에서 드래그 영역과 버튼 클릭 영역 충돌 방지(버튼은 드래그 영역 제외).

## 테스트

- TTS 출력은 OS 의존이라 자동화가 어렵다. **순수 상태 로직만 분리해 단위 테스트**:
  - `startRepeat(n)` 후 `remaining`이 n으로 설정되는지
  - 발화 종료 체인이 `remaining`을 1씩 감소시키는지
  - `remaining`이 0이 되면 `isAutoPlaying`이 false로 끝나는지
  - `stop()`이 상태를 리셋하는지
- Web Speech API는 테스트에서 **fake 객체로 주입**(의존성 주입)하여 발화 호출 횟수를 검증.
- 테스트 러너: node test runner.
- 음성 실제 출력·윈도우 표시·디자인은 수동 확인.
